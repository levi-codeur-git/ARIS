# Phase 8 — Git / GitHub

## Objectif
Versionner le projet ARIS et organiser ses ressources afin de disposer d'un dépôt exploitable comme support d'apprentissage et portfolio technique.

## Réalisation
Le projet utilise Git avec une branche principale `main` et un dépôt GitHub public. L'organisation sépare notamment la documentation, les scripts Linux, les fichiers systemd, le réseau, les captures et les éléments de sécurité.

Les scripts et configurations créés pendant les phases précédentes sont conservés dans une structure versionnée.

## Résultat
ARIS dispose d'une base Git/GitHub permettant de suivre les évolutions du projet et de présenter le travail réalisé.
